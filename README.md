# 餘燼信標 · Ashlight

原創繁體中文等角生存遠征遊戲，部署於 GitHub Pages。

## 遊玩
- WASD／方向鍵移動，或點選地面尋路；手機使用方向按鈕。
- 靠近箱子或衣櫃按 E 搜刮，逐件轉移物資。
- 空白鍵攻擊相鄰敵人；R 觀察一回合。
- 林地取得木材，街區取得電路板與金屬。
- 回基地製作信標，從遠征面板開始守夜；守住三波即可撤離。
- 食水不足會扣生命；生命歸零失敗。建議製作長矛、繃帶與營火。
- 每次動作自動存於本機 localStorage。暫停選單可重新開始（須再次確認）。

## 技術
零執行期套件，原生 ES modules + Canvas 2D 原創程序等角美術。這是 2.5D 等角投影，不是 WebGL/GLB 3D 引擎。所有程式、美術圖元、地形與動畫為此專案創作，未使用參考遊戲的角色、商標或素材。UI 物品符號由系統字型／Emoji 呈現，無第三方素材下載或再散布。

靜態伺服器：`python -m http.server 8044`。測試：`npm test`（Node 20+）。

## 測試範圍
tests/engine.test.js 明確使用單元測試場景；tests/playthrough.test.js 從新遊戲經 act() 合法操作，驗證實際地圖完整通關與資源耗盡失敗，未注入捷徑狀態。另測存取守恆、背包容量、扣料與重複升級、建造與生成碰撞、戰鬥掉落及損壞存檔。

單人回合制短篇體驗；無多人、帳號或雲端存檔。重新整理保留進度，清除網站資料將移除存檔。
